# Paper Records

This directory records the papers corresponding to the reproduced source code.

For public GitHub use, the repository keeps paper metadata, official links,
BibTeX-style references, and local PDF candidate paths. Full PDF files are not
committed by default because publisher and conference redistribution terms can
vary across ACL, IEEE, arXiv, and workshop papers.

See `docs/PAPER_INDEX.md` for the source-to-paper mapping. Each copied source
directory under `reproduced/` also has a `PAPER.md` file.
