## 项目概述

TempoBERT是一种时序上下文语言模型，通过在文本中添加时间信息并执行时间掩码（Time Masking）来建模语言的动态演化。该模型可用于：

1. **句子时间预测**: 预测给定句子属于哪个时间段
2. **语义变化检测**: 检测词语随时间的语义演变

## 运行实验

### 方式一：快速演示（推荐）

运行快速演示，仅需约30秒完成：

```bash
source venv/bin/activate
python quick_demo.py
```

演示包含：
- 加载少量数据（2个时间点，1000条文本）
- 训练模型（50步）
- 时间预测演示
- 语义变化检测演示

### 方式二：完整实验

#### 1. 训练TempoBERT模型

```bash
python run_experiment.py \
    --mode train \
    --data_path datasets \
    --output_dir output/tempobert_full \
    --base_model bert-base-uncased \
    --num_epochs 3 \
    --batch_size 16 \
    --max_length 128 \
    --mlm_probability 0.15 \
    --time_mlm_probability 0.5
```

参数说明：
- `--mode`: 运行模式 (train/predict/semantic_change/demo)
- `--data_path`: 数据目录路径
- `--output_dir`: 模型输出目录
- `--base_model`: 基础BERT模型
- `--num_epochs`: 训练轮数
- `--batch_size`: 批次大小
- `--max_length`: 最大序列长度
- `--mlm_probability`: 普通token的掩码概率
- `--time_mlm_probability`: 时间token的掩码概率

#### 2. 句子时间预测

```bash
python run_experiment.py \
    --mode predict \
    --model_path output/tempobert_full \
    --input_text "The economy is growing rapidly."
```

#### 3. 语义变化检测

```bash
python run_experiment.py \
    --mode semantic_change \
    --model_path output/tempobert_full \
    --data_path datasets \
    --test_words "virus,phone,network,cloud,technology" \
    --max_sentences 100
```

### 方式三：Python代码调用

```python
from tempobert_compat import (
    train_tempobert,
    predict_time,
    compute_semantic_change_score,
    TempoBertTokenizer
)
from transformers import BertForMaskedLM

# 1. 训练模型
trainer = train_tempobert(
    train_data_path="datasets",
    output_dir="output/my_model",
    times=["1990", "2000", "2010", "2020"],
    num_epochs=2,
    batch_size=16
)

# 2. 加载已训练的模型
model = BertForMaskedLM.from_pretrained("output/my_model")
tokenizer = TempoBertTokenizer.from_pretrained("output/my_model")
tokenizer.times = ["1990", "2000", "2010", "2020"]

# 3. 时间预测
probs = predict_time(model, tokenizer, "The internet changed everything.", device="cpu")
print(probs)
# 输出: {'<2010>': 0.35, '<2020>': 0.30, '<2000>': 0.25, '<1990>': 0.10}

# 4. 语义变化检测
time_sentences = {
    "1990": ["Technology is advancing rapidly.", ...],
    "2020": ["New technology emerges daily.", ...]
}
score = compute_semantic_change_score(model, tokenizer, "technology", time_sentences)
print(f"语义变化分数: {score}")
```

## 核心原理

### 1. 时间Token嵌入

TempoBERT在每个句子前添加时间标记token：
```
原始: The economy is growing.
处理后: <1990> The economy is growing.
```

### 2. 时间掩码 (Time Masking)

训练时，时间token使用更高的掩码概率（默认0.5），促使模型学习文本与时间的关联。

### 3. 语义变化检测

通过比较词语在不同时间点的上下文嵌入向量，计算余弦距离来衡量语义变化程度。

## 常见问题

### Q1: 训练时间过长？

可以减少训练数据量或训练步数：
```bash
python run_experiment.py --mode train --max_times 4 --num_epochs 1
```

### Q2: 内存不足？

减小批次大小：
```bash
python run_experiment.py --mode train --batch_size 8
```

### Q3: 如何使用GPU？

代码会自动检测CUDA/MPS（Apple Silicon），无需额外配置。

### Q4: 时间预测概率为0？

这是因为训练不充分。增加训练轮数和数据量可以改善：
```bash
python run_experiment.py --mode train --num_epochs 5
```

## 技术细节

### 模型架构

- 基础模型: BERT-base-uncased (12层, 768隐藏维度)
- 词汇表扩展: 添加时间token (<年份>)
- 损失函数: 掩码语言模型 (MLM) 损失

### 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| mlm_probability | 0.15 | 普通token掩码概率 |
| time_mlm_probability | 0.5 | 时间token掩码概率 |
| max_length | 128 | 最大序列长度 |
| learning_rate | 5e-5 | 学习率 |
